# Google Business Profile audit and launch checklist

This is an owner-operated checklist. It does not record completion until the signed-in profile and supporting evidence have been reviewed.

## Identity and NAP

- Match the profile name to the verified real-world business name; do not add keywords.
- Reconcile phone, website, address or service-area configuration with the facts registry.
- Confirm the map pin at the real customer-facing location.
- Use accurate seasonal and special hours.

## Categories and services

- Confirm the primary category is the closest available car-rental category.
- Add only secondary categories and services the business currently provides.
- Remove scooter, motorcycle, ATV, quad and buggy services.
- Do not add attributes, delivery areas, or opening times that lack owner evidence.

## URLs and measurement

- Website URL: `https://naxos-carrentals.com/?utm_source=google&utm_medium=organic&utm_campaign=gbp`
- Booking URL: use the verified booking-engine destination with `utm_source=google&utm_medium=organic&utm_campaign=gbp_booking` only if the booking integration preserves those parameters.
- Test both destinations on mobile before saving.

## Trust assets

- Upload original exterior/office, owner/team, fleet and handover photographs.
- Use accurate captions; do not use stock or AI-generated proof imagery.
- Answer Q&A from the owner account using only approved operational facts.

## Review request

Send one neutral request after each completed rental. No incentives, sentiment filtering, employee pressure, or review gating.

Suggested workflow:

1. Trigger only after the rental is marked complete.
2. Send the same request to every eligible renter.
3. Link directly to the verified Google review form.
4. Do not include personal data in analytics events.
5. Record delivery, not the customer’s sentiment.

The final customer-facing Greek message must be written and approved by the named native Greek professional and owner before activation.
